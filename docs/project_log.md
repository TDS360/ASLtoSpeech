# Project Log

Jot down what you tried, what broke, and how you fixed it each time
you work on the project. District judges often ask directly about
problems you ran into — real notes make that easy to answer instead
of trying to remember it on the spot.

## Entry format
```
## [Date] — What I worked on
- What I did:
- What worked:
- What broke / was confusing:
- What I'll try next:
```
